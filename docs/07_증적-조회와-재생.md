# 증적 조회와 재생

수신·송출한 메시지는 **증적 로그**(audit log)로 남습니다. 증적 로그를 조회하고, 다시 재생(replay)하는 명령어입니다.

| 명령어 | 설명 |
|---|---|
| `kc audit-log` | 증적 로그 조회·검색·복사 |
| `kc play` | 증적 로그 재생 |
| `cli` | 대화형 터미널. 증적 로그와 전문 설정을 상세 조회 |

## kc audit-log

증적 로그를 **흐르는 대로 보는(tail)** 명령어입니다. 세부 명령어와 증적 이름(`name:`)을 줍니다. 세부 명령어 없이 실행하면 안내 문구만 나옵니다.

| 세부 명령어 | 설명 |
|---|---|
| `kc audit-log tail` | 증적 로그에 tail 을 걸어 들어오는 프레임을 시각, 채널, 전문 종류, 순번으로 한 줄씩 봄 |
| `kc audit-log tailstat` (`tail-stat`) | 증적 로그에 tail 을 걸어 전문 종류별 건수 통계를 봄 |

```bash
kc audit-log tail name:rcv                 # rcv 증적 전체
kc audit-log tail name:rcv head:AB         # 전문 종류 AB 만
kc audit-log tail name:rcv chid:101        # 채널 101 만
kc audit-log tailstat name:rcv             # 전문별 건수 통계
```

| 인자 | 설명 |
|---|---|
| `name:` (또는 `file:`) | 증적 이름. 예) `rcv`, `dist`. **필수** |
| `date:` | 증적 날짜(`YYYYMMDD`). 기본은 오늘 |
| `head:` | 전문 종류로 거름 |
| `chid:` (또는 `rid:`) | 채널로 거름 |

!!! note "아직 동작하지 않는 세부 명령어"
    `list`, `copy`, `find` 는 이름은 있으나 현재는 안내 문구만 출력하고 아무 작업도 하지 않습니다. 증적 파일을 찾을 때는 `ls $v17/data/dlog` 로 확인하세요.

## kc play

증적 로그를 일괄 재생합니다. `키:값` 인자로 대상과 구간, 속도를 지정합니다. 인자 없이 실행하면 사용법을 보여줍니다.

```bash
kc play name:rcv date:20261109 start_hhmmss:53000 end_hhmmss:193059 speed:1.0 print:true
```

| 인자 | 설명 |
|---|---|
| `name:` | 증적 종류. 예) `rcv`, `dist`, `hub`. **필수** |
| `date:` | 증적 날짜. 예) `20250104` |
| `start_hhmmss:` | 시작 시각. 예) `53000` (05:30:00) |
| `end_hhmmss:` | 종료 시각. 예) `193059` (19:30:59) |
| `speed:` | 재생 속도 배율. `1.0` 실시간, `0.5` 2배 느리게, `2.0` 2배 빠르게 |
| `print:` | `true` 면 데이터를 화면에 출력 |
| `throw_to:` | 재생한 데이터를 전달할 프로세스. 예) `kqp.1` |
| `script:` | 프레임마다 실행할 사용자 함수 파일(`[이름].moon`) |
| `outfile:` | 통계(count/stat) 모드의 출력 파일 |
| `remove_head:` | 재생 시 메시지 헤더를 제거 |
| `with-cfg:` | 상세 옵션 파일을 참조 |
| `usage:` | 사용법과 예제 출력 |

!!! warning "재생은 실제로 전달됩니다"
    `throw_to:` 를 지정하면 재생한 메시지가 해당 프로세스로 **실제 전달**됩니다. 운영 서버에서는 대상을 확인하고 실행하세요.

## cli

증적 로그와 전문 설정을 상세하게 조회하는 **대화형 터미널**입니다.

```bash
cd $v17/bin
./cli
```

| 명령어 | 설명 |
|---|---|
| `menu` | 터미널 화면 목록 |
| `go [화면]` | 해당 화면으로 이동 |
| `e [스크립트]` | 스크립트를 즉시 실행(eval) |
| `help` | 현재 화면에서 쓸 수 있는 명령어 목록 |

`go [화면]` 으로 이동할 수 있는 화면입니다. 서버에 있는 화면 전체는 `menu` 로 확인합니다.

| 화면 | 설명 |
|---|---|
| `go audit` | 증적 로그 상세 조회 |
| `go spec` | 전문 정의서 조회 |
| `go identify` | 식별자(identify) 조회 |
| `go stat` | 통계 조회 |
| `go node` | 노드 정보 조회 |
| `go memory` | 공유메모리(종목별) 조회 |
| `go entry` | 시작 화면(로고) |

화면 안에서는 `help` 로 그 화면에서 쓸 수 있는 명령어를 봅니다.
