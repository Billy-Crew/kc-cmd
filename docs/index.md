# KC Command 소개

**kc**는 PMR·시세 FEP 서버의 프로세스와 서비스를 다루는 터미널 명령어 도구입니다. `kc <명령어> [인자]` 형식으로 실행하며, 서버 초기 설정부터 서비스 기동, 모니터링, 증적 조회와 재생까지 운영에 필요한 작업을 한 곳에서 처리합니다.

이 사이트는 운영자가 자주 쓰는 명령어를 **명령어와 설명** 중심으로 정리한 사용 안내입니다.

## 실행 방법

```bash
# 설치 직후 한 번: kc 와 환경변수 설정
bin/kc init
source ~/.bash_profile

# 이후에는 어느 위치에서나
kc <명령어> [인자]
```

- 인자는 `키:값` 형식(`date:20261109`)과 위치 인자(`kc ps pmr`)를 함께 씁니다.
- 프로세스를 지정할 때는 `<애플리케이션>.<인스턴스>` 형식의 **프로세스 코드**(예: `pmr.KS_f`)를 씁니다.
- 프로세스 기동·종료처럼 되돌리기 어려운 명령은 확인 입력(`YES`)을 요구하며, `force`를 붙이면 확인 없이 실행합니다.

!!! note "kc 와 vcli"
    `kc` 로 실행하는 명령은 `./vcli <명령어>` 로도 실행할 수 있습니다. 이 문서는 `kc` 기준으로 씁니다.

## 명령어의 종류

| 종류 | 설명 |
|---|---|
| 핵심 명령어 | 서버 설정, 서비스, 프로세스, 증적 조회처럼 항상 제공되는 명령어 (`init`, `service`, `ps`, `play` 등) |
| 시스템 명령어 | 서버 상태를 다루는 유틸리티. 사이트 설정에 의존하지 않음 (`u_clear_cache_and_memory` 등) |
| 사이트 명령어 | 서버의 환경 설정(`env.moon`, 레이아웃, 채널 사전)에 맞춰 동작하는 명령어 (`set-emit`, `check-pulse`, `all-services` 등) |
