# 모니터와 증적 탐색

수신 현황을 터미널에서 계속 지켜보거나, 증적을 화면에서 탐색하는 조회 명령어입니다. 모두 **조회만** 하고 설정이나 데이터를 바꾸지 않습니다.

| 명령어 | 설명 |
|---|---|
| `kc u_chn2` | 채널(CHID)별 건수와 마지막 수신 시각 모니터 |
| `kc u_spec2` | 종목(spec)별 건수와 마지막 수신 시각 모니터 |
| `kc knav-audit` | 증적 로그를 화면에서 탐색하는 Audit Navigator |

## kc u_chn2

채널별 누적 건수와 증가분을 표로 보여 줍니다.

```bash
kc u_chn2 name:rcv0 intv:1
```

| 인자 | 설명 |
|---|---|
| `name:` | 조회 대상 이름. 생략하면 `rcv0` |
| `intv:` | 갱신 간격(초). 생략하면 한 번만 출력. 0.1 보다 커야 반복 갱신 |

| 열 | 설명 |
|---|---|
| `CHID` | 채널 번호 |
| `PORT` | 포트 |
| `TIME` | 마지막 수신 시각 |
| `CNT` | 누적 건수 |
| `INCR` | 직전 갱신 대비 증가 건수 |

## kc u_spec2

`kc u_chn2` 와 같은 방식으로, **종목(spec) 단위**로 건수를 보여 줍니다.

```bash
kc u_spec2 name:rcv0 intv:1
```

- 인자는 `kc u_chn2` 와 같습니다 (`name:`, `intv:`).
- 열은 `CHID`, `TIME`, `CNT`, `INCR` 입니다.

!!! note "프로세스별 통계를 읽습니다"
    두 명령은 실행 중인 프로세스가 남기는 통계(`tmem`)를 읽습니다. 해당 프로세스가 떠 있지 않으면 표시할 내용이 없습니다.

## kc knav-audit

증적 로그를 목록에서 골라 내용을 보는 터미널 화면 도구(Audit Navigator)입니다. 화면은 세 단계(증적 선택, 프레임 목록, 상세)로 나뉩니다.

```bash
kc knav-audit
```

- 인자 없이 실행합니다.
- 증적을 조건으로 검색해 파일로 뽑으려면 `kc audit-log` 나 [증적을 TXT/CSV로 변환하기](09_증적-TXT-CSV-변환.md)를 사용합니다.
