# 초기 설정과 점검

서버를 처음 설치한 뒤 설정을 만들고, 구동 전에 설정이 맞는지 확인하는 명령어입니다.

| 명령어 | 설명 |
|---|---|
| `kc init` | 초기 서버 설정(최초 1회). 환경변수를 점검 |
| `kc compile` | 채널 사전 등 설정을 컴파일 |
| `kc test` | 구동 환경, 초기 설정, 채널 I/O 점검 |
| `kc run-TEST` | `cfg/test-suite` 의 테스트 묶음 실행 |

## kc init

설치 직후 **한 번** 실행합니다.

```bash
bin/kc init
source ~/.bash_profile
kc test env
```

`init` 후에는 `source ~/.bash_profile` 로 환경변수를 적용하고, `kc test env` 로 결과를 확인합니다.

## kc compile

서버별 설정 파일(`cfg/env.moon`)을 만든 뒤 채널 사전을 컴파일합니다.

```bash
cd $v17
cp cfg/env_[node].moon cfg/env.moon
cp cfg/local_const_[node].moon cfg/local_const.moon
kc compile
```

!!! note "서버별 설정 파일"
    `[node]` 자리에는 이 서버의 이름을 넣습니다. 예를 들어 서버 이름이 `alpha1` 이면 `cfg/env_alpha1.moon` 과 `cfg/local_const_alpha1.moon` 을 복사합니다. 서버별 파일 이름은 `ls cfg/env_*.moon` 으로 확인합니다.

## kc test

하위 명령어를 인자로 줍니다. 인자 없이 실행하면 하위 명령어 목록을 보여줍니다. 잘못된 하위 명령어를 주면 사용 예(`kc test env`)를 안내합니다.

| 명령어 | 설명 |
|---|---|
| `kc test env` | 환경설정 점검. 시스템 버전, 준비 상태, 레이아웃 수, 송출 상태 확인 |
| `kc test init` | `kc test env` 와 **같은 점검**. 초기 설정 직후 확인용 이름 |
| `kc test io` | 채널 I/O 설정 점검. 필수 설정 파일과 송출 채널, 환경 정보 확인 |
| `kc test help` | `test` 하위 명령어 목록 |

```bash
kc test env      # 구동 전에 가장 먼저 확인
kc test io
```

### kc test env (= kc test init)

다음 순서로 출력합니다.

| 항목 | 내용 |
|---|---|
| 시스템 버전 | 실행 바이너리 버전(`binary.ver`), 스크립트 라이브러리 버전(`slib.ver`), `DBISAM_BUF_SIZE`, `MQ_MSG_SIZE` |
| 준비 상태 | `kc init` 초기화 이력(최초 초기화 날짜·시각), 필수 파일 존재 여부: `cfg/env.moon`(ENV 환경설정), `cfg/channel_dictionary.json`(채널사전). 없으면 `NO` 와 함께 안내 |
| 레이아웃 수 | 이 서버에 설정된 레이아웃 수 |
| 송출 상태 | **송출 가능** 여부 (PMR 송출 값 = `.runtime` 파일). `kc set emit:on` 의 결과를 여기서 확인 |

!!! note "송출 상태에는 KQP 가 나오지 않습니다"
    `kc test env` 의 송출 상태는 PMR 값입니다. KQP 의 송출 값은 `kc set-emit status` 로 확인합니다.

초기화한 적이 없으면 `bin/kc init` 으로 초기화하라는 안내가 나옵니다.

### kc test io

1. 필수 파일 3개가 있는지 확인합니다: `cfg/local_const.moon`(통합시세 송출 채널), `cfg/env.moon`(PMR 환경), `cfg/dict_channels.moon`(채널사전 원본). 하나라도 없으면 오류를 출력하고 끝납니다.
2. 통합시세 **송출 채널**(KQP OUTBOUND)의 설정을 출력합니다.
3. `ENV` 환경 정보를 출력합니다.

## kc run-TEST

`cfg/test-suite/[이름].moon` 에 정의된 테스트 묶음(suite)을 실행합니다.

```bash
kc run-TEST [suite 이름]
```
