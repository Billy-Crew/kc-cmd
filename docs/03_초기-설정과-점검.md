# 초기 설정과 점검

서버를 처음 설치한 뒤 설정을 만들고, 구동 전에 설정이 맞는지 확인하는 명령어입니다.

| 명령어 | 설명 |
|---|---|
| `kc init` | 초기 서버 설정(최초 1회). 환경변수를 점검 |
| `kc compile` | 채널 사전 등 설정을 컴파일 |
| `kc test` | 구동 환경, 초기 설정, 채널 I/O 점검 |
| `kc run-TEST` | `cfg/test-suite` 의 테스트 묶음 실행 |

## kc init

설치 직후 **한 번** 실행합니다.

```bash
bin/kc init
source ~/.bash_profile
kc test env
```

`init` 후에는 `source ~/.bash_profile` 로 환경변수를 적용하고, `kc test env` 로 결과를 확인합니다.

## kc compile

서버별 설정 파일(`cfg/env.moon`)을 만든 뒤 채널 사전을 컴파일합니다.

```bash
cd $v17
cp cfg/env_prod_dome1.moon cfg/env.moon
cp cfg/local_const_prod_dome1.moon cfg/local_const.moon
kc compile
```

!!! note "서버별 설정 파일"
    위 파일 이름은 국내 운용서버 #1의 예입니다. 서버에 맞는 `env_*.moon`, `local_const_*.moon` 을 고릅니다.

## kc test

세부 명령어를 인자로 줍니다. 인자 없이 실행하면 도움말을 보여줍니다.

| 명령어 | 설명 |
|---|---|
| `kc test env` | 환경설정 점검. 시스템 버전, 필수 설정 파일의 존재 여부, **송출 상태** 확인 |
| `kc test init` | 초기 설정 점검. 바이너리 버전, 서버 설정 파일과 채널 설정 파일 확인 |
| `kc test io` | 채널 I/O 설정 점검. 서버별 입수·송출 환경, 호스트 IP 설정 확인 |
| `kc test help` | `test` 하위 명령어 목록 |

```bash
kc test env      # 구동 전에 가장 먼저 확인
kc test io
```

## kc run-TEST

`cfg/test-suite/<이름>.moon` 에 정의된 테스트 묶음(suite)을 실행합니다.

```bash
kc run-TEST <suite 이름>
```
