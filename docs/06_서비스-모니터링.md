# 서비스 모니터링

프로세스와 채널이 정상인지 확인하는 명령어입니다.

| 명령어 | 설명 |
|---|---|
| `kc ps` | 프로세스 목록 조회. 떠 있어야 하는데 없는 프로세스는 `missed` 로 표시 |
| `kc stat` | 채널별 건수와 마지막 수신 시각 조회 |
| `kc queue` | 프로세스 간 메시지 큐 크기 조회 |
| `kc check-pulse` | 증적에 최근 수신(또는 송출)이 실제로 기록됐는지 점검 |
| `kc u_diag_local_node` | 로컬 노드 진단 |
| `kc log` | 프로세스별 텍스트 로그 보기(tail) |
| `kc strace` | 프로세스에 `strace` 를 붙여 시스템 콜을 실시간으로 확인 |

## kc ps

```bash
kc ps          # 전체 프로세스
kc ps pmr      # pmr 프로세스 그룹만
```

서버 설정(`env.moon`)에 등록된 프로세스 중 떠 있지 않은 것은 `missed` 로 표시됩니다.

## kc stat

수신한 채널별 통계 등을 봅니다. 종류를 첫 번째 인자로 줍니다. 생략하면 채널별(`chid`)입니다.

| 명령어 | 설명 |
|---|---|
| `kc stat` (`kc stat chid`) | 채널별 건수, 마지막 수신 시각, 초당 건수(TPS). `rid`, `chids`, `chns` 도 같은 뜻 |
| `kc stat proc` | 프로세스 상태. 전체 중 실행 중인 수와 비정상 프로세스 목록. `process` 도 같은 뜻 |
| `kc stat batch` | 일일 배치 작업(캐시 파일 리셋, 캐시 메모리 리셋, 종목마스터 송출)의 수행 여부 |

```bash
kc stat                       # 채널별
kc stat proc                  # 프로세스 상태
```

## kc queue

프로세스 간 메시지 큐(`/dev/mqueue/vnt.*`)의 크기를 보여 줍니다. 큐가 128개를 넘으면 문제로 표시합니다. 큐가 쌓이면 뒤쪽 프로세스가 느리거나 멈춘 것입니다.

```bash
kc queue
```

## kc check-pulse

현재 서버가 받아야 하는 RID 가 최근 구간에 실제로 증적(`rcv*`)에 기록됐는지 점검합니다. `prefix:dist` 를 주면 서버가 **송출**해야 하는 RID 가 `dist*` 증적에 기록됐는지 점검합니다.

```bash
kc check-pulse                                   # 최근 180초, 수신 점검
kc check-pulse prefix:dist                       # 송출 점검
kc check-pulse excepts:101,102                  # 점검에서 뺄 RID
kc check-pulse date:20261012 at:162700           # 과거 시점으로 재생해 점검
kc check-pulse full:on                           # 구간 전체를 읽어 정확한 건수 집계
```

| 인자 | 설명 |
|---|---|
| `prefix:` | 증적 파일 종류. 기본 `rcv`. `dist` 로 시작하면 송출 점검 |
| `now:` | 조사 시작 시각(초, 음수). 기본 `-180` |
| `stale:` | 마지막 수신 후 이 초를 넘으면 문제. 기본 `180` |
| `excepts:` | 점검에서 제외할 RID 목록 (쉼표 구분) |
| `date:`, `at:` | 과거 시점(`YYYYMMDD`, `HHMMSS`) 기준으로 점검 |
| `full:on` | 구간 전체를 읽어 건수를 정확히 집계 |

## kc u_diag_local_node

로컬 노드의 상태를 진단해 보여 줍니다.

| 인자 | 설명 |
|---|---|
| `json:true` | JSON 으로 출력 |
| `nodiag` | 진단 없이 표시만 |

## kc log

프로세스의 텍스트 로그를 `tail -f` 로 봅니다. 오늘 날짜 로그가 기본이고, 날짜를 주면 그날 로그를 봅니다.

```bash
kc log pmr.p1                # 오늘 로그
kc log pmr.p1 20261109       # 날짜 지정
```

로그 파일은 `$v17/log/[날짜].[애플리케이션].[인스턴스].log` 입니다.

## kc strace

실행 중인 프로세스에 `strace` 를 붙여, 그 프로세스가 호출하는 시스템 콜을 실시간으로 봅니다. 프로세스가 멈추거나 느릴 때 어디서 막혀 있는지 확인하는 용도입니다.

```bash
kc strace [애플리케이션].[인스턴스]
kc strace pmr.p1
```

- 프로세스 코드는 `kc ps` 로 먼저 확인합니다.
- 실행하면 대상 프로세스의 PID 로 `strace -p [PID]` 를 실행하고, 출력을 그대로 보여 줍니다. 끝내려면 `Ctrl+C` 를 누릅니다.
- 인스턴스를 빼거나(`kc strace pmr`) 실행 중인 프로세스가 아니면 `nevermind.` 만 출력하고 끝납니다.

!!! warning "운영 중에는 짧게 사용하세요"
    `strace` 는 대상 프로세스를 추적하는 동안 그 프로세스를 느리게 할 수 있습니다. 시세를 처리하는 프로세스에는 필요한 시간만 짧게 붙이세요. 서버에 `strace` 가 설치되어 있어야 하고, 대상 프로세스를 추적할 권한(일반적으로 같은 사용자 또는 root)이 필요합니다.
