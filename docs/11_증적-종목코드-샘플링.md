# 증적 종목코드 샘플링

증적(`.audit`)에서 **종목별로 고르게 전문을 뽑아 새 증적을 만드는** 명령어입니다. 전문 종류마다, 종목마다 일정 건수만 남겨 작은 시험용 증적을 만들 때 씁니다.

```bash
kc u_issue_sampler stat   name:rcv date:20260727
kc u_issue_sampler sample name:rcv date:20260727 n:20 m:20 out:rcvSMP
```

| 하위 명령 | 설명 |
|---|---|
| `stat` | 전문별·종목별 통계를 출력 |
| `sample` | 통계를 참조해 종목 교차 샘플링 후 새 증적을 기록 |

| 인자 | 설명 |
|---|---|
| `name:` | 입력 증적 이름 (필수) |
| `date:` | 입력 증적 날짜 `YYYYMMDD`. 생략하면 오늘 |
| `n:`, `m:` | 샘플링 개수 (`sample`) |
| `out:` | 출력 증적 이름 (`sample`) |
| `time:`, `remove_head:` 등 | `kc play` 인자를 그대로 사용 |

## 먼저 알아 둘 것

- **출력 파일의 날짜는 입력 증적이 아니라 실행일입니다.** 파일 이름이 `<out>_<실행일>.audit` 으로 만들어집니다.
- 출력 증적이 이미 있으면 거부합니다. 덮어쓰려면 `overwrite:on`, 이어붙이려면 `append:on` 을 줍니다.
- 입력 증적은 `.dat` 와 `.idx` 가 **한 쌍 모두** 있어야 열립니다.
- **종목코드 자동 해석은 spec 이 등록된 국내 전문에서만** 됩니다. 해외 전문은 위치를 직접 줍니다.

```bash
# 해외 전문 예) 종목코드 위치를 직접 지정
kc u_issue_sampler sample name:rcvMDX date:20260727 \
  remove_head:37 hlen:5 icode_off:25 icode_len:32 out:mdxSMP
```

위치를 주지 않으면 종목별이 아니라 전문 종류(head)별로 `m` 건씩만 뽑습니다.

!!! note "종목 필터가 필요하면"
    "이 조건에 맞는 전문만" 뽑아 텍스트로 보려면 [증적을 TXT/CSV로 변환하기](09_증적-TXT-CSV-변환.md)가 더 맞습니다. 이 명령은 **새 증적(재생용)** 을 만드는 용도입니다.
