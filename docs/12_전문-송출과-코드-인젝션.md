# 전문 송출과 코드 인젝션

실행 중인 프로세스에 **직접 명령이나 전문을 보내는** 명령어입니다. 시험과 진단에 씁니다.

!!! danger "운영 서버에서는 주의하세요"
    이 명령어들은 실행 중인 프로세스에 실제로 메시지를 전달합니다. 받는 프로세스의 상태와 송출에 영향을 줄 수 있으므로, 무엇을 어디로 보내는지 확인하고 실행하세요. 특히 `kqp.1` 에 많은 양을 한꺼번에 보내면 프로세스가 종료될 수 있습니다.

| 명령어 | 설명 |
|---|---|
| `kc u_throw_proc` | 프로세스의 프로시저를 JSON 으로 호출. 코드 인젝션에도 사용 |
| `inject2` | 코드 인젝션 짧은 형식 (`bin` 에 있는 명령) |
| `kc kdebug` | 터미널 편집기로 코드를 작성해 인젝션하고 결과를 확인 |
| `kc u_throw_spec` | 전문 1개(또는 시험 묶음)를 프로세스에 던져 보기 |

## kc u_throw_proc

```bash
kc u_throw_proc <app> <inst> <procedure> ['{JSON 옵션}']
```

| 인자 | 설명 |
|---|---|
| `app` | 받을 앱 이름 |
| `inst` | 받을 인스턴스 이름 |
| `procedure` | 실행할 프로시저 이름 |
| JSON 옵션 | 프로시저에 넘길 값. 생략하면 `{}` |

- `app`, `inst`, `procedure` 중 하나라도 빠지면 안내만 출력하고 보내지 않습니다.
- JSON 형식이 올바르지 않으면 보내지 않습니다.

## kc u_throw_proc 로 코드 인젝션

프로시저 이름을 `inject2` 로 주면 지정한 스크립트를 프로세스 안에서 실행합니다.

```bash
kc u_throw_proc kqp 1 inject2 '{"fname":"ci_test01"}'
```

- 스크립트는 `$v17/data/mtemp/<이름>.moon` 에서 읽습니다. 경로가 **고정**이라 다른 위치에 두면 찾지 못합니다.
- 스크립트에서 오류가 나면 해당 프로세스 로그에 `code error` 가 남습니다.

## inject2

위 명령의 짧은 형식입니다.

```bash
inject2 kqp 1 ci_test01
inject2 kqp 1 ci_test01 '{"p01":"YES","count":100}'
```

| 인자 | 설명 |
|---|---|
| 1, 2번째 | 앱 이름, 인스턴스 이름 |
| 3번째 | 스크립트 이름 (`data/mtemp/<이름>.moon`) |
| 4번째(선택) | 스크립트에 넘길 JSON |

## kc kdebug

터미널에서 인젝션 코드를 편집하고 실행해 결과를 보는 디버그 패드입니다.

```bash
kc kdebug kqp 1
```

- 앱과 인스턴스를 생략하면 `kqp` 의 `3` 번 인스턴스로 보냅니다.
- 실행 결과는 `/tmp/tmp_outbuf.json` 으로 돌아오고 화면에 표로 출력됩니다. 60초 안에 결과가 없으면 `timeout:` 을 출력합니다.
- 인젝션하는 스크립트 이름은 `tmp_ci_temporary` 입니다.

## kc u_throw_spec

시세 전문을 만들어 프로세스에 던집니다. 입수 처리 흐름을 시험할 때 씁니다.

```bash
kc u_throw_spec [종류] [거래소] [app] [inst] [횟수]
kc u_throw_spec fill krx kqp 1 1
```

| 순서 | 인자 | 기본값 | 설명 |
|---|---|---|---|
| 1 | 종류 | `fill` | 보낼 전문 종류. `all` 은 준비된 샘플 전체를 KRX·NXT 순으로 재생 |
| 2 | 거래소 | `krx` | `krx` 또는 `nxt` |
| 3 | app | `kqp` | 받을 앱 |
| 4 | inst | `1` | 받을 인스턴스 |
| 5 | 횟수 | `1` | 같은 전문을 반복해 보내는 횟수 |

- 샘플은 `cfg/test_packet.moon` 에서 읽습니다. 종류에 해당하는 샘플이 없으면 내장된 짧은 시험 전문을 보냅니다.
- 횟수를 크게 주면 짧은 시간에 많은 전문이 들어갑니다. 운영 중인 `kqp.1` 에는 사용하지 마세요.
