# 송출 설정

Active 송출 서버는 **송출 설정을 켜야** UDP 송출이 동작합니다. 송출 여부는 `kc set` 과 `kc set-emit` 으로 바꿉니다. 두 명령은 **설정하는 범위가 다릅니다.**

| 명령어 | 설정되는 곳 | 존재하는 서버 |
|---|---|---|
| `kc set-emit [on 또는 off] ...` | **KQP 와 PMR 모두** (대상 선택 가능) | **신규 서버에만** |

## kc set-emit

KQP 와 PMR 의 송출 플래그를 한 번에 조회하고, 대상을 골라 설정합니다. **신규 서버에만 있는 명령어**입니다.

### 현황 조회

| 명령어 | 설명 |
|---|---|
| `kc set-emit status` | KQP, PMR(`.runtime` 파일), PMR 프로세스의 송출 플래그 현황. PMR 프로세스는 파일 값과 **다른 것만** 나열 |
| `kc set-emit status detail` | PMR 프로세스를 전부 나열 |
| `kc set-emit status json:true` | JSON 출력 |

### 설정

끝에 `force` 를 붙이면 확인 없이 실행합니다.

| 명령어 | 설정되는 곳 |
|---|---|
| `kc set-emit [on 또는 off] kqp` | KQP 공유메모리만 |
| `kc set-emit [on 또는 off] pmr` | PMR 전체(`.runtime` 파일 + 실행 중인 모든 PMR 프로세스) |
| `kc set-emit [on 또는 off] pmr.[인스턴스]` | PMR 프로세스 하나. **메모리 값만** 바꾸므로 재기동하면 파일 값으로 돌아감 |
| `kc set-emit [on 또는 off] all` | 서버 전체(KQP + PMR) |

```bash
kc set-emit status
kc set-emit on pmr.p1
kc set-emit off all force
```

## 어느 명령어를 쓰나요

- 신규 서버에서 송출을 켜고 끄고 현황을 확인할 때: `kc set-emit`
- `kc set-emit` 이 없는 서버: `kc set emit:on|off` (PMR) + KQP 송출 설정(`cli`)
