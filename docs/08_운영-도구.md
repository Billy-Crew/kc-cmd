# 운영 도구

서버 운영 중 필요할 때 쓰는 도구 명령어입니다. 일부는 **데이터를 지우거나 초기화**하므로, 무엇을 지우는지 확인하고 실행하세요.

| 명령어 | 설명 |
|---|---|
| `kc strace` | 프로세스에 `strace` 를 붙여 시스템 콜을 실시간으로 확인 |
| `kc t_switchover_emit` | 같은 그룹에서 지정한 노드만 송출 ON, 나머지 노드는 송출 OFF 로 원격 전환 |
| `kc u_clear_cache_and_memory` | 캐시 파일(`_SAV_*.json`)을 지우고, KQP 캐시와 공유메모리 종목 정보를 초기화 |
| `kc u_clear_cachefiles` | 캐시 파일 `data/fdata/_SAV_*.json` 만 삭제 |
| `kc u_cleanse_files` | 같은 이름의 `.moon` 이 있는 `.lua` 파일 삭제 |
| `kc u_gen_poll2` | POLL 전문 생성 후 프로세스에 전달 |
| `kc u_compare_dict_json` | 채널 사전 JSON 비교 |

## 지우는 명령어 한눈에 비교

| 명령어 | 지우는 것 | 지우지 않는 것 |
|---|---|---|
| `kc u_clear_cachefiles` | `$v17/data/fdata/_SAV_*.json` 파일 | 메모리, 그 밖의 파일 |
| `kc u_clear_cache_and_memory` | ① `$v17/data/fdata/_SAV_*.json` 파일 ② KQP 의 종목 캐시(메모리) ③ 공유메모리의 종목 정보 | 프로세스(계속 실행), 증적 로그, 그 밖의 파일 |
| `kc u_cleanse_files` | `.moon` 과 같은 이름·같은 디렉터리에 있는 `.lua` 파일 | `.moon` 파일, 이름이 겹치지 않는 `.lua` 파일 |

## kc u_clear_cachefiles

KQP 통합시세가 쓰는 **캐시 파일만** 삭제합니다. 메모리는 건드리지 않습니다.

```bash
kc u_clear_cachefiles
```

- 지우는 것: `$v17/data/fdata/_SAV_*.json` (`rm -f`)

## kc u_clear_cache_and_memory

캐시 파일과 캐시 메모리, 공유메모리를 **모두** 초기화합니다. 실행하면 `YES` 입력을 요구합니다. 이 명령은 파일을 직접 지우지 않고, **실행 중인 프로세스에 초기화를 지시**합니다.

```bash
kc u_clear_cache_and_memory
```

| 순서 | 지시를 받는 프로세스 | 하는 일 |
|---|---|---|
| 1 | `sweeper.1` | 캐시 파일 삭제: `$v17/data/fdata/_SAV_*.json` |
| 2 | `kqp.1`, `kqp.ksp_f`, `kqp.ksp_q`, `kqp.ksq_f`, `kqp.ksq_q` | 일일 초기화(`do_daily_reset`): 종목 캐시(메모리) 초기화 |
| 3 | `sweeper.1` | 공유메모리의 모든 종목 정보 초기화(`clear_master`) |

!!! warning "실행 중인 프로세스가 필요합니다"
    `sweeper.1` 과 `kqp.*` 가 떠 있어야 초기화가 수행됩니다. 종목 마스터와 누적 정보가 지워지므로 운영 중에는 영향을 확인하고 실행하세요.

## kc u_cleanse_files

소스 디렉터리에서 **같은 이름의 `.moon` 이 있는 `.lua` 파일**을 삭제합니다. `.moon` 으로 컴파일되는 소스의 중복본을 정리합니다.

```bash
kc u_cleanse_files purge          # 삭제 대상을 보여 주고 YES 확인 후 삭제
kc u_cleanse_files purge force    # 확인 없이 삭제
```

- 대상 디렉터리: `$v17/data/code`, `$v17/data/raw_lib`, `$v17/data/mtemp` (각 디렉터리 안에서만 짝을 찾음)
- 지우는 것: `[이름].lua` — 같은 디렉터리에 `[이름].moon` 이 있을 때
- `purge` 없이 실행하면 **아무것도 지우지 않습니다.** 삭제 대상도 보여 주지 않고 `it is already cleaned` 만 출력합니다.
- 삭제 대상이 없으면 `it is already cleaned` 를 출력합니다.

## kc strace

실행 중인 프로세스에 `strace` 를 붙여, 그 프로세스가 호출하는 시스템 콜을 실시간으로 봅니다. 프로세스가 멈추거나 느릴 때 어디서 막혀 있는지 확인하는 용도입니다.

```bash
kc strace [애플리케이션].[인스턴스]
kc strace pmr.p1
```

- 프로세스 코드는 `kc ps` 로 먼저 확인합니다.
- 실행하면 대상 프로세스의 PID 로 `strace -p [PID]` 를 실행하고, 출력을 그대로 보여 줍니다. 끝내려면 `Ctrl+C` 를 누릅니다.
- 인스턴스를 빼거나(`kc strace pmr`) 실행 중인 프로세스가 아니면 `nevermind.` 만 출력하고 끝납니다.

!!! warning "운영 중에는 짧게 사용하세요"
    `strace` 는 대상 프로세스를 추적하는 동안 그 프로세스를 느리게 할 수 있습니다. 시세를 처리하는 프로세스에는 필요한 시간만 짧게 붙이세요. 서버에 `strace` 가 설치되어 있어야 하고, 대상 프로세스를 추적할 권한(일반적으로 같은 사용자 또는 root)이 필요합니다.

## kc t_switchover_emit

액티브 노드가 바뀔 때 송출을 전환합니다. 그룹(`group:`)과 새 액티브 노드(`active_node:`)를 모두 지정하면, **지정한 노드는 송출을 켜고 같은 그룹의 나머지 노드는 송출을 끕니다.** 노드에는 원격으로 요청합니다.

```bash
kc t_switchover_emit group:[그룹] active_node:[node]
kc t_switchover_emit group:alpha active_node:alpha1     # 예시
```

예를 들어 그룹 `alpha` 에 노드 `alpha1`, `alpha2` 가 있을 때 `group:alpha active_node:alpha1` 을 실행하면 다음과 같이 바뀝니다.

| 노드 | 결과 |
|---|---|
| `alpha1` | 송출 ON |
| `alpha2` | 송출 OFF |

그룹과 노드 이름은 명령 안에 정의돼 있어 서버 구성마다 다릅니다. `alpha`, `alpha1`, `alpha2` 는 예시입니다.

- 지정한 노드가 그 그룹에 속하지 않으면 아무것도 바꾸지 않고 오류를 JSON 으로 알려 줍니다.
- 노드 이름은 명령어 안에 고정돼 있으므로 서버 구성이 바뀌면 함께 고쳐야 합니다.
- 인자가 없으면 호출 형식을 JSON 으로 알려 줍니다.

## kc u_gen_poll2

POLL(연결 확인) 전문을 만들어 지정한 프로세스에 전달합니다.

```bash
kc u_gen_poll2 [프로세스코드] [인자]
kc u_gen_poll2 pmr.p1 rid:2 data:ABC
```

## kc u_compare_dict_json

채널 사전 JSON 파일을 비교합니다.

```bash
kc u_compare_dict_json
kc u_compare_dict_json file:cfg/aaa.json
```
