# 명령어 한눈에 보기

이 문서가 다루는 명령어 24개입니다. 자세한 사용법은 각 장을 보세요.

## 초기 설정과 점검

| 명령어 | 설명 |
|---|---|
| `kc compile` | 채널 사전 등 설정 컴파일 |
| `kc test` | 구동 환경, 초기 설정, 채널 I/O 점검 |
| `kc run-TEST` | `cfg/test-suite` 의 테스트 묶음 실행 |

## 송출 설정

| 명령어 | 설명 |
|---|---|
| `kc set-emit` | 송출 플래그 조회와 설정. **KQP 와 PMR 모두** 설정 가능 (신규 서버에만 있음) |

## 서비스 기동과 종료

| 명령어 | 설명 |
|---|---|
| `kc service` | 서비스(레이아웃) 단위 기동·종료·조회 |
| `kc all-services` | `env.moon` 에 등록된 서비스 전체를 기동·종료 |
| `kc run` | 프로세스 기동 |
| `kc kill` | 프로세스 종료 |
| `kc lockclear` | 중복 실행 방지용 락 파일 삭제 |

## 서비스 모니터링

| 명령어 | 설명 |
|---|---|
| `kc ps` | 프로세스 목록 조회. 떠 있어야 하는데 없는 프로세스는 `missed` 로 표시 |
| `kc stat` | 채널별 건수와 마지막 수신 시각 조회 |
| `kc queue` | 프로세스 간 메시지 큐 크기 조회 |
| `kc check-pulse` | 증적에 최근 수신(또는 송출)이 실제로 기록됐는지 점검 |
| `kc u_diag_local_node` | 로컬 노드 진단 |
| `kc log` | 프로세스별 텍스트 로그 보기(tail) |
| `kc strace` | 프로세스에 `strace` 를 붙여 시스템 콜을 실시간으로 확인 |

## 증적 조회와 재생

| 명령어 | 설명 |
|---|---|
| `kc audit-log` | 증적 로그 실시간 조회·통계 |
| `kc play` | 증적 로그 재생 |
| `cli` | 대화형 터미널. 증적 로그와 전문 설정을 상세 조회 |

## 운영 도구

| 명령어 | 설명 |
|---|---|
| `kc u_switchover_emit` | 같은 그룹에서 지정한 노드만 송출 ON, 나머지 노드는 송출 OFF 로 원격 전환 |
| `kc u_clear_cache_and_memory` | 캐시 파일(`_SAV_*.json`)을 지우고, KQP 캐시와 공유메모리 종목 정보를 초기화 |
| `kc u_clear_cachefiles` | 캐시 파일 `data/fdata/_SAV_*.json` 만 삭제 |
| `kc u_gen_poll` | POLL 전문 생성 후 프로세스에 전달 |
| `kc u_compare_dict_json` | 채널 사전 JSON 비교 |
