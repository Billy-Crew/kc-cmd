# 명령어 한눈에 보기

이 문서가 다루는 명령어 34개입니다. 자세한 사용법은 각 장을 보세요.

## 초기 설정과 점검

| 명령어 | 설명 |
|---|---|
| `kc init` | 초기 서버 설정(최초 1회). 환경변수 점검 |
| `kc compile` | 채널 사전 등 설정 컴파일 |
| `kc test` | 구동 환경, 초기 설정, 채널 I/O 점검 |
| `kc run-TEST` | `cfg/test-suite` 의 테스트 묶음 실행 |

## 송출 설정

| 명령어 | 설명 |
|---|---|
| `kc set` | 런타임 설정 변경. `emit:on`, `emit:off` 는 **PMR 만** 설정 |
| `kc set-emit` | 송출 플래그 조회와 설정. **KQP 와 PMR 모두** 설정 가능 (신규 서버에만 있음) |

## 서비스 기동과 종료

| 명령어 | 설명 |
|---|---|
| `kc service` | 서비스(레이아웃) 단위 기동·종료·조회 |
| `kc all-services` | `env.moon` 에 등록된 서비스 전체를 기동·종료 |
| `kc run` | 프로세스 기동 |
| `kc kill` | 프로세스 종료 |
| `kc lockclear` | 중복 실행 방지용 락 파일 삭제 |

## 서비스 모니터링

| 명령어 | 설명 |
|---|---|
| `kc ps` | 프로세스 목록 조회. 떠 있어야 하는데 없는 프로세스는 `missed` 로 표시 |
| `kc stat` | 채널별 건수와 마지막 수신 시각 조회 |
| `kc queue` | 프로세스 간 메시지 큐 크기 조회 |
| `kc check-pulse` | 증적에 최근 수신(또는 송출)이 실제로 기록됐는지 점검 |
| `kc u_diag_local_node` | 로컬 노드 진단 |
| `kc log` | 프로세스별 텍스트 로그 보기(tail) |
| `kc strace` | 프로세스에 `strace` 를 붙여 시스템 콜을 실시간으로 확인 |

## 증적 조회와 재생

| 명령어 | 설명 |
|---|---|
| `kc audit-log` | 증적 로그 조회·검색·복사 |
| `kc play` | 증적 로그 재생 |
| `cli` | 대화형 터미널. 증적 로그와 전문 설정을 상세 조회 |

## 운영 도구

| 명령어 | 설명 |
|---|---|
| `kc t_switchover_emit` | 같은 그룹에서 지정한 노드만 송출 ON, 나머지 노드는 송출 OFF 로 원격 전환 |
| `kc u_clear_cache_and_memory` | 캐시 파일(`_SAV_*.json`)을 지우고, KQP 캐시와 공유메모리 종목 정보를 초기화 |
| `kc u_clear_cachefiles` | 캐시 파일 `data/fdata/_SAV_*.json` 만 삭제 |
| `kc u_cleanse_files` | 같은 이름의 `.moon` 이 있는 `.lua` 파일 삭제 (`data/code`, `data/raw_lib`, `data/mtemp`) |
| `kc u_gen_poll2` | POLL 전문 생성 후 프로세스에 전달 |
| `kc u_compare_dict_json` | 채널 사전 JSON 비교 |

## 모니터와 증적 탐색

| 명령어 | 설명 |
|---|---|
| `kc u_chn2` | 채널별 건수와 마지막 수신 시각 모니터 |
| `kc u_spec2` | 종목별 건수와 마지막 수신 시각 모니터 |
| `kc knav-audit` | 증적을 화면에서 탐색하는 Audit Navigator |

## 증적 종목코드 샘플링

| 명령어 | 설명 |
|---|---|
| `kc u_issue_sampler` | 증적에서 종목별로 고르게 뽑아 새 증적 생성 (`stat`, `sample`) |

## 전문 송출과 코드 인젝션

| 명령어 | 설명 |
|---|---|
| `kc u_throw_proc` | 프로세스의 프로시저를 JSON 으로 호출. 코드 인젝션에도 사용 |
| `inject2` | 코드 인젝션 짧은 형식 (`bin` 에 있는 명령) |
| `kc kdebug` | 터미널 편집기로 코드를 인젝션하고 결과 확인 |
| `kc u_throw_spec` | 전문 1개(또는 시험 묶음)를 프로세스에 던져 보기 |
